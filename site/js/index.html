@swamidasslab/xpict — TypeScript client + WASM paint for browser and Node. RDKit.js stays at the layout edge.

Open align demo API examples

Quick start

import { xpict } from "@swamidasslab/xpict";

const mol = xpict.mol("c1ccccc1");
const rendered = await xpict.render(mol);
const svg = xpict.toSvg(rendered.scene);
