Python

Package xpict on PyPI — declarative molecule depiction for publication-quality vector graphics. Source under python/xpict/. Paint via Rust _native.depict_molecule; RDKit as an optional layout extra.

Install

uv sync --extra rdkit
./scripts/build_bindings.sh py

Publish workflow: .github/workflows/pypi.yml (tag py/v*).

Live contracts

from xpict import DepictSpec, MolSpec

doc = DepictSpec.model_validate({
    "molecules": [
        {"smiles": "CCO", "mark_atoms": [2]},
        {"smiles": "CCCO", "align_to": 0},
    ]
})

Full nested PictSpec remains under xpict.future for design — not the publish surface.

Label markup

Star / chem labels share one Rust dialect: $R_1$, R^2, \alpha, **bold** / *italic*. Bare my_name stays literal. See label-markup.md.

Lab engine

Pict(backend="rdkit").render(…) still exercises multi-mol / diagram paths used in tests and POCs while the public client settles on mol / render / to_svg.
