Install

Publishing setup (tokens, trusted publishing, tags) lives in the repo as docs/publish.md.

JavaScript

Package @xenosite/xpict on npmjs.org: 

npm install @xenosite/xpict

Tag js/v* or run Publish JS package in Actions (needs repo secret NPM_TOKEN). Interactive demo: /js/demo/.

Python

uv sync --extra rdkit
# or: pip install xpict[rdkit]  (once on PyPI)

Native extension via maturin (xpict-py → xpict._native). RDKit is an optional extra for layout.

Rust

# Cargo.toml
xpict = "0.1"           # public API (needs system RDKit)
# or paint-only:
xpict-core = "0.1"

Publish xpict-core first, then xpict. System RDKit + Boost required to build the public crate. See language page Rust.
