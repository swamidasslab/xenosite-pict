Rust

Declarative molecule depiction for publication-quality SVG in native Rust: xpict-core (paint) and xpict (public API + RDKit layout).

Public crate

use xpict::{mol, MolRenderOptions};

let mut m = mol("CCO")?;
let svg = m.render(MolRenderOptions {
    mark_atoms: Some(vec![2]),
    ..Default::default()
})?.to_svg();

System deps

  • RDKit C++ libraries + headers
  • Boost (serialization)
  • C++17 compiler

Ubuntu 202309 may need the FileWriters.h shim under crates/xpict/compat/. See crate README.

Workspace note

xpict is a workspace member but not a default-member, so CI coverage on xpict-core does not require system RDKit. Python and WASM packages never depend on the RDKit-backed crate.

Label markup

Chem / star labels: $R_1$, R^2, \alpha, **bold** / *italic* via xpict_core::markup (internal dialect, not KaTeX). See label-markup.md.
